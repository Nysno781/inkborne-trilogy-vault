# Canon Status Register

> The single scoreboard for every checkable fact in the trilogy: one row per fact, one status per row. The narrative docs (character files, bibles, outlines) keep telling the story — this file is the control panel that says what is actually canon.

---

## Legend

| Marker | Meaning |
| :--- | :--- |
| 🔒 locked | Author-confirmed canon. Changes only by an explicit new ruling. |
| 🔓 open | Deliberately undecided. Nobody locks it by accident. |
| ❌ discarded | Ruled out. Parked in the graveyard with its reason — retrievable, but not canon. |
| 🔶 default | An AI-suggested placeholder never ratified by the author. The audit converts every one of these to 🔒 or 🔓. |

**Answer key (for rulings):** **L** = lock it · **O** = leave open · **D** = discard · add a note anytime.

---

## How a pass works

1. Every checkable fact in the domain gets extracted and cross-checked vault-wide.
2. The author receives one **bulk-ratify list** (consistent everywhere — one word locks them all) plus at most **8 real rulings** (genuine conflicts).
3. The author answers in shorthand (L / O / D per number).
4. Rulings get applied everywhere, frontmatter statuses synced, the pass committed, and the changelog updated.

Rules: one domain per pass · pause anytime · every ruling reversible · discarded ≠ deleted.
